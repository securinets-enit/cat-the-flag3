Installation

Extract the archive and run the bundled install script:

tar -xzf gh_2.42.1_linux_amd64.tar.gz
cd gh_2.42.1_linux_amd64
sudo ./install.sh

Or install via your package manager:

sudo apt install ./gh_2.42.1_linux_amd64.deb

What's new in v2.42.1
