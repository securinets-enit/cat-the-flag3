# Docker Basics Tutorial

Welcome to the Securinets ENIT Docker Basics tutorial.

This container is an interactive lesson on Docker fundamentals. Follow
the prompts. Three flags are hidden along the way.

## What you'll learn

- Pulling images from a registry
- Running containers interactively
- The container filesystem model
- Environment variables in containers
- Inspecting image metadata
