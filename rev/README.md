# Reverse Engineering Wave 1

Twenty beginner-to-intermediate reverse-engineering tasks are organized into
two learning arcs:

1. `01`-`10`: runtime reversing, decoding, VM state, Python bytecode, and .NET reflection.
2. `11`-`20`: packed artifacts, damaged ELF/PE headers, runtime unpacking, and memory dumping.

Every task contains `attachments/`, `README.md`, `writeup.md`, and
`solver/solve.py`. Organizer-only source and rebuild notes are kept under
`src/`, `build/`, and `build.sh`; distribute only the player-facing files.
